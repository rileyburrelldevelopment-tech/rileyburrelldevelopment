Accessibility

Accessibility is part of the architecture.

EchoPath is designed around accessible interaction from the start rather than adding accessibility after the interface is finished.

VoiceOver and TalkBack

EchoPath is designed for VoiceOver on iOS and TalkBack on Android. Labels, hints and spoken feedback vary by platform and build.

Manual speech when requested

Explicit Read actions are designed to work independently from automatic speech reduction where appropriate.

Clear visual structure

Large controls, readable contrast, dark and light mode support and non-colour-only communication help make information easier to perceive.

Less unnecessary complexity

Navigation choices, status information and feature screens are repeatedly simplified when testing shows that an interface is too crowded.

Accessibility feedback

Real testing changes the product.

EchoPath is developed through repeated device testing and beta feedback. Accessibility bugs are treated as product bugs, not optional polish.

Send accessibility feedback

Website accessibility

This website is built with semantic headings, keyboard-accessible navigation, visible focus styles, reduced-motion support, text-based content and responsive layouts. If something is difficult to use, please report it.
